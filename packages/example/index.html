MText Renderer Example

Rendering

Lazy skips preload and redraws on fontLoaded. Off preloads before render. Use Release Fonts, then Render to compare.

Fonts

Accepts .shx / .ttf / .otf / .woff. Cached entries show [cached] in the lists.
